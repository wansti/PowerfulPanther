# PowerfulPanther — Sound Effects List

All are 8-bit or chiptune style to match the pixel art, saved as `.wav`.

## Sound Effects

| Sound effect          | Priority     | Trigger                                 | Notes                                                             |
| --------------------- | ------------ | --------------------------------------- | ----------------------------------------------------------------- |
| Jump                  | Must-have    | Player presses jump                     | Short and light                                                   |
| Land                  | Must-have    | Mao touches the ground                  | Soft thud                                                         |
| Transform to Panther  | Must-have    | Kitten turns into panther               | Powerful, rising                                                  |
| Transform to Kitten   | Must-have    | Panther turns back into kitten          | Deflating, falling: the sound of "losing power"                   |
| Hairball land         | Must-have    | A hairball hits the ground              | Soft, squishy thump; clear enough to catch the player's attention |
| Level clear           | Must-have    | Mao enters the cat door                 | Short, rewarding jingle                                           |
| Transform blocked     | Nice-to-have | Transform pressed with no room to grow  | Short "denied" buzz                                               |
| Menu select / confirm | Nice-to-have | Navigating menus                        | Simple UI blips                                                   |
| Name entry typing     | Nice-to-have | Typing the cat's name                   | Tiny click per letter                                             |
| Arrive home           | Nice-to-have | Mao squeezes through the final cat flap | Warm, gentle ending sting                                         |
